# Designing Data-Intensive Applications

**The Big Ideas Behind Reliable, Scalable, and Maintainable Systems**
*by Martin Kleppmann*

Reading notes and code experiments for the book, organized by Part. Each
part is its own subfolder containing per-chapter notes and runnable
examples.

## Structure

Each part folder follows the same layout:

```
part-N-name/
  README.md              # part overview + chapter index
  chNN-chapter-name/
    notes.md              # key concepts, summary, questions/takeaways
    examples/              # code samples for that chapter
```
